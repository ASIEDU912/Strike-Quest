# StrikeQuests v9.2 — Flexible Seasonality Controls

## New
- Replaces fixed 5/10/15/20-year seasonality dropdown with a 1–25 year slider.
- Uses exact calendar-year ranges, avoiding the previous off-by-one observation behavior.
- Adds Specific Years mode with individual year buttons modeled after the StockCharts workflow.
- Adds one-tap Previous Year and Current YTD selections.
- Allows arbitrary combinations of available calendar years.
- Single-year analysis labels results as positive/negative in the selected year instead of implying a long historical tendency.

Seasonality remains an informational research input and is not a forecast.
