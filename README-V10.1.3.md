# v10.1.3: Lumi across the research journey

Lumi now helps in Research, Seasonality, Saved, Watchlist and Quests. Quests has the full evolution card; other placements are compact, inline and collapsible. Every guide button navigates to existing controls or evidence. It never changes data mode, loads a saved idea, fetches quotes, saves research, selects comparisons or awards a milestone for navigation.

- Research explains the current horizon, correction and source context, or points back to invalid inputs.
- Seasonality describes the selected range and actual current-month observation count, including empty and small samples. The sample-evidence text stays synchronized when year selections change.
- Saved guides reflection without marking an idea reviewed. Deleting a loaded record immediately clears its review eligibility.
- Watchlist helps compare source, session, horizon and correction assumptions without ranking investments.
- Quests uses the existing next-achievable-milestone logic. Research rewards and all five cosmetic forms are unchanged.

Lumi greets each visible placement once per session. Seasonality adds a curious look, Saved a thoughtful nod and Watchlist a gentle drone scan. Existing breathing, tail, blink, wing, aura and genuine milestone effects remain. Every placement shares pause and collapse preferences; reduced motion, hidden views, offscreen cards and Settings stop animation. Milestones use one live announcement, and navigating never replays a reward.

## Invariants

Fresh sessions still start with 2-Year, 10% correction and the existing divisor. Saved horizon/correction overrides restore unchanged. XP comes only from valid dated core badge records; all nine total 500 XP, and Thoughtful Return remains separate. Abilities are cosmetic, not forecasting capabilities. No backend, provider, credential, analytics or paid-service changes.
