# Predictive ticker/company search

The ticker field now supports:
- local predictive matches for common U.S. stocks and ETFs with no API key
- full Barchart OnDemand predictive search when a Barchart API key is saved
- search by ticker symbol or company/fund name
- symbol, name, exchange/type displayed in the dropdown
- tap/click selection and keyboard arrow/Enter support

Barchart endpoint used: getSymbolLookUp.
