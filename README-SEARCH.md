# Predictive ticker/company search

The ticker field searches the existing bundled catalog of 50 common U.S. stocks and ETFs by symbol or company/fund name. Suggestions are immediate and local in every mode, including Automatic. Typing does not contact a provider or require an API key. This is a small local catalog, not a complete market directory; an unmatched ticker can still be entered directly and analyzed through the existing data flow.

The combobox exposes expanded state, active option and selection to assistive technology. Arrow keys move through matches; Enter commits the active match. Escape, Tab, blur and clearing dismiss the list. Tap/click uses the same selection path. Existing app artwork is reused where available, with a text fallback for other catalog symbols. No logo service is used.

Quick Picks lives in the opening Research instrument card below compact Lumi. Its original buttons, logos and ETF provider labels remain intact. In Automatic mode a committed selection may start the existing EOD data request; suggestions themselves never do. Saved research, journals and XP are unaffected by browsing symbols.
