STRIKE PRICE LAB — WINDOWS PC + IPHONE INSTALL GUIDE

You do NOT need a Mac or Xcode.

WHAT YOU NEED
- Windows PC
- iPhone 13 Pro
- A free GitHub account (recommended) or another HTTPS web host

OPTION A — GITHUB PAGES (FREE)

ON YOUR WINDOWS PC
1. Go to github.com and sign in.
2. Create a new repository. Example name:
   strike-price-lab
3. Keep it Public.
4. Open the new repository and choose:
   Add file → Upload files
5. Unzip StrikePriceLab-iPhone-PWA.zip.
6. Upload everything INSIDE the unzipped folder:
   - index.html
   - manifest.webmanifest
   - sw.js
   - README.md
   - icons folder
7. Commit the files.
8. Open:
   Settings → Pages
9. Under “Build and deployment” choose:
   Source: Deploy from a branch
10. Choose:
    Branch: main
    Folder: / (root)
11. Save.
12. GitHub will provide a site address similar to:
    https://YOUR-USERNAME.github.io/strike-price-lab/

ON YOUR IPHONE 13 PRO
1. Open the GitHub Pages address in SAFARI.
2. Verify Strike Price Lab loads.
3. Tap Safari's Share button.
4. Scroll down and tap:
   Add to Home Screen
5. Keep the name “Strike Lab” or rename it.
6. Tap Add.
7. Launch Strike Lab from your iPhone Home Screen.

After installation it opens in its own full-screen window and behaves much more like a normal iPhone app.

MARKET DATA
- Manual mode works immediately.
- Alpha Vantage mode is optional.
- Add your API key inside the app if you want automatic price/history lookup.
- The key is saved in that browser/app's local storage.

UPDATES
Whenever you replace files in the GitHub repository, the hosted app will update.
If iPhone appears to keep an older cached version, fully close the app and reopen it.
