# Strike Quest — Strike Price Calculator

**Find smarter entry zones with data, discipline, and progress.**

Strike Quest is a gamified, mobile-first strike-price and entry-target calculator for stocks and ETFs. It turns the research workflow into four stages: trend context, market position, historical performance, and Low/Mid/High strike-zone targets.

## Public-facing features
- Predictive search by ticker, company, or ETF/fund name
- 3M / 6M / 1Y / 2Y / 3Y research horizons
- Correction and holding-divisor controls
- Low / Mid / High strike-zone targets
- Research score, badges, market mood, and quest progress
- Saved analyses with load/delete controls
- Shareable result summaries
- Manual mode plus optional Barchart OnDemand integration
- iPhone, Android, tablet, and desktop PWA support

## Install as an app
### iPhone / iPad
Open the GitHub Pages URL in Safari → Share → **Add to Home Screen** → keep **Open as Web App** enabled.

### Android
Open the site in Chrome/Edge/Samsung Internet → **Install app** or **Add to Home screen**.

## Data note
The calculator is informational. Automatic Barchart data requires the user's own authorized Barchart OnDemand access unless a secure backend is added later.
